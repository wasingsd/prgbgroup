# PR Global Group

## Platform
Web. Existing Next.js 16 / React 19 application with Tailwind CSS 4 and static export deployment.

## Product purpose
Present the group's China–Thailand cargo and travel services, explain cargo services and rates, and let visitors contact the company or access its existing cargo portal.

## Confirmed scope
Preserve the existing roles, factual content, services, rates, and functions of the home, PR Cargo, and contact pages. PR Travel remains an external website; preserve the existing /pr-travel redirect as a compatibility route.

## Brand commitments
The user selected a white-led corporate design with PR Cargo red, black text, small yellow accents, and an alpaca mascot inspired by the supplied images. Use the typography and component conventions of the sibling prgb-travel-group project. Attached promotional copy is reference material, not requested website content.

## Constraints
Preserve existing contact destinations and form integration. Do not copy contact details, analytics, licenses, business claims, or travel facts from the sibling project. No deployment requested.
